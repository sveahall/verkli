## Manual UI script

Local preview: `npm run dev -w @verkli/web -- --port 3142`, then `/dev/agent-memory`. This development-only page simulates API responses in session storage, blocks real API/provider calls and never writes to the production database. For a real account, open a book's AI specialist in Author Studio.

1. Open **Team memory**, save a preference for **This book**, switch specialist and verify it is visible. Edit it and verify the changed text.
2. Save a preference for **This edition**. Switch edition and verify the book preference remains but the edition preference is absent.
3. Send a message, reopen/reload the assistant and verify the conversation returns as read-only history. Start a new conversation and select the old one in **History**.
4. Choose **Temporary conversation**, send a message, leave temporary mode and verify it was not added to saved history and saved preferences were not used.
5. In the local fixture, enable **Simulate storage failure**, reopen the assistant, type a draft and press Ctrl/Cmd+Enter. Verify the draft remains and sending is disabled; retry after disabling the failure. Enable delayed replies and switch Edith → Alma → Edith during a reply; both turns must remain and the next prompt must continue the same thread.
6. In a disposable test conversation, export loaded history, forget a preference and delete the conversation. Verify the correct confirmation, that separately saved preferences remain, and that reload cannot resurrect deleted content.

## Scope

Only explicitly saved preferences and bounded conversation history are included. Automatic inferred memories, summaries and full-narration pronunciation changes are deferred. The simulated preview is not evidence of live provider behaviour; production API checks are recorded separately in the release evidence.
